# 浏览器书签分类索引

## 本项主由AI辅助完成，基本功能已实现,使用体验正在逐步优化中。

这是一个基于浏览器原生书签的 popup 快速启动插件。

核心体验：

- 搜索相关网页书签。
- 通过多级分类快速浏览和打开书签。
- 直接打开固定入口中的最近常用书签。

当前已完成 popup 第一版，并新增后台管理页第一版。

## 使用方法

1. 在 Chrome 或 Microsoft Edge 的扩展管理页面开启开发者模式。
2. 选择“加载已解压的扩展”，加载本项目根目录。
3. 点击浏览器工具栏中的插件图标，打开 popup 书签分类启动器。
4. 首次使用时可在 popup 中手动同步浏览器书签，之后通过搜索、分类列表和最近常用入口快速打开书签。
5. 需要调整分类、同步、规则或 AI 配置时，进入插件的后台管理页进行设置。

## 文档

- `PROJECT_STATUS.md`：当前项目进度，接手或读取进度时先看这个文档。

- `PRODUCT_REQUIREMENTS.md`：产品需求。

- `BACKEND_CONTROL.md`：后台管理开发说明，后续做 options page、后台同步、规则中心、AI 配置时优先读取。
- `后台管理页当前版本修改意见.md`：记录当前后台管理页 UI 和功能修改意见。

后台管理相关内容已从 popup 交互文档中拆出，避免后续开发后台时被 popup 细节干扰。popup 前端不内置分类匹配规则，后台只维护本地设置、本地分类、本地关联、规则和后续 AI 配置。
